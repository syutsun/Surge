# 每日统一更新时间

GitHub Actions 在北京时间每天 07:00（UTC 前一天 23:00）启动。统一任务按以下顺序运行：

去开屏模块 → AI 规则 → Tracking 规则 → 个性化流媒体规则 → Direct+ 规则 → Direct 规则 → 自定义名称模块 → 原样同步规则和模块。

- 有转换或个人设置的文件由各自的流程处理。独立 Spotify 和综合流媒体规则共用个人补充，四个自定义名称模块保留自己的显示名。
- `config/Upstream-mirrors.json` 维护原样同步清单，包括 14 份规则和 3 个模块，保留上游原始字节。某个来源下载或校验失败时保留上一版，其他文件继续处理，任务会报告失败。
- 各流程读取 main 的最新版本，只在通过校验且内容变化时提交。前一步失败后，后续流程仍可继续。
- Actions 中可手动触发统一任务或对应流程。修改工作流时会触发统一任务，生成文件的提交不会再次触发同步。
- Google.list 和 T-Mobile.list 沿用现有内容，暂未指定自动同步来源。

07:00 是计划启动时间，GitHub 可能延迟。各设备的 09:00 Surge 外部资源刷新是独立的。公开仓库长期无活动时，GitHub 可能停用定时任务。
