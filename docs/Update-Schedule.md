# 每日统一更新时间

所有已配置的自动同步统一由 `.github/workflows/daily-update.yml` 触发：

- 北京时间每天 07:00，对应 UTC 前一天 23:00，cron 为 `0 23 * * *`。
- 一个统一任务自动依次调用 10 个现有同步流程，避免同时写入仓库产生冲突。
- 每个流程开始时取 main 的最新内容，保留之前流程刚生成的文件。
- 某个来源失败会保留其上一版；后续其他同步流程仍会继续运行，整体任务会显示失败便于发现问题。
- 有内容变化且通过原有校验时才提交，所有个人规则和排除项继续生效。
- 每个原有工作流仍支持手动运行，修改对应脚本或个人配置仍可触发即时更新。
- 修改工作流配置会触发一次统一运行，验证调度连接。自动生成文件提交不会递归触发。

顺序：去开屏模块 → AI 规则 → 广告规则 → Tracking 规则 → Apple 规则 → 流媒体规则 → 六份通用规则 → Direct+ 规则 → Direct 规则 → 其他模块。

07:00 是计划触发时间，不表示所有文件同时完成。GitHub 调度可能延迟；需要即时获取时可手动运行统一任务。
公开仓库长期无活动时，GitHub 可能停用定时任务，需在 Actions 中重新启用。
